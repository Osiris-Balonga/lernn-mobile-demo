# Lernn Mobile Demo

## Purpose

Présenter fidèlement l'espace élève Lernn Mobile sans dépendre d'une API. Les visiteurs peuvent se connecter avec un compte de démonstration ou une carte élève, puis explorer des données scolaires complètes.

## Platform

Web statique mobile-first, publié sur GitHub Pages. Sur ordinateur, l'application reste centrée dans une surface mobile lisible.

## Audience

Écoles, parents et partenaires découvrant Lernn lors d'une démonstration commerciale ou produit.

## Design contract

La référence visuelle et interactionnelle est Lernn Mobile : palette Émeraude, DM Sans, navigation basse Accueil / Notifications / Compte, modules élève et composants existants. Il ne s'agit pas d'un redesign.

## Security boundary

Toutes les données sont fictives. Aucun appel à Lernn API n'est permis et aucun jeton QR brut ne doit être versionné.
